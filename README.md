## `01 / SYSTEM OVERVIEW`

I'm a Computer Science Engineering student building practical applications with **Generative AI, Retrieval-Augmented Generation (RAG), LLMs, and modern web technologies**. This portfolio brings together my experiments, projects, and learning in intelligent software.

> **Mission:** turn useful ideas into accessible, thoughtfully engineered software.

## `04 / FEATURED PROJECTS`

<details open>
<summary><b>◈ Ask My Document — RAG Document Intelligence</b></summary>

Ask natural-language questions about documents through a retrieval-augmented workflow.

- Document ingestion and text processing
- Semantic retrieval concept using embeddings
- LLM responses grounded in retrieved context

[Explore source code →](https://github.com/rasswanthsura-cpu/ask-my-doc)
</details>

<details>
<summary><b>◈ Smart DB Assistant — Natural Language to SQL</b></summary>

An LLM-powered Python assistant that translates questions about a movies table into read-only SQL, runs the query, and explains the result.

- Python, LangChain, Ollama (Llama 3)
- MySQL access through SQLAlchemy/LangChain
- Basic read-only query validation

[Explore source code →](https://github.com/rasswanthsura-cpu/smart_db_assitant)
</details>

## `05 / RUN LOCALLY`

Requirements: Node.js and npm.

```bash
git clone https://github.com/rasswanthsura-cpu/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
