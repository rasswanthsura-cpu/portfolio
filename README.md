## 🚀 Run Locally

Prerequisites: Node.js and npm.

```bash
git clone https://github.com/rasswanthsura-cpu/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
